# 📝 커밋 메시지 컨벤션 (Commit Convention)

개인 프로젝트에서도 **일관된 커밋 메시지 작성**은 협업 능력과 관리 효율을 높여줍니다.  
아래 규칙에 따라 커밋 메시지를 작성해주세요 👇

---

## ✅ 커밋 태그 종류

| 태그 | 설명 |
|------|------|
| `Add` | 새로운 파일 추가 |
| `Del` | 기존 파일 삭제 |
| `Feat` | 새로운 기능 추가 |
| `Fix` | 버그 수정 |
| `Style` | 코드 스타일 수정 (정렬, 들여쓰기 등) |
| `Refactor` | 코드 리팩토링 (기능 변경 없이 구조 개선) |
| `Chore` | 빌드 설정, gitignore 수정 등 기타 변경 |
| `Design` | UI 디자인 관련 변경 (예: 버튼 색상, 폰트 등) |
| `Rename` | 파일 또는 폴더 이름 변경 |
| `Remove` | 파일 또는 폴더 삭제 (Del과 유사하나 더 명시적) |

---

## 🧾 커밋 메시지 작성 예시

```bash
Feat: 몬스터 AI 이동 패턴 추가  
Fix: 적이 공격하지 않는 버그 수정  
Style: PlayerController 들여쓰기 정리  
Chore: .gitignore 유니티 기본 설정 추가  
Design: 인벤토리 UI 폰트 및 버튼 정리
